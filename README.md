# The Bluff Club

**Trust No One. Play Your Hand.** — *Your Room. Your Rivals. Your Table.*

A private club for friends who play Bluff, Poker, Teen Patti and house card games in person.
Record results from your phone in seconds; leaderboards, streaks, rivalries, tournaments and
seasons build themselves from the record.

This is a friendly scorekeeping app. Points are leaderboard points — no deposits, wagering or
payments.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Supabase (Postgres, Auth,
Storage, Row Level Security) · Vitest · PGlite (in-process Postgres for database tests).

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in your Supabase URL + publishable key
npm run dev
```
